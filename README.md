# ETF-EDA

네이버 금융의 ETF 정보를 활용해 시장 흐름을 탐색하는 분석 프로젝트입니다.

## 분석 내용

- ETF별 현재가, 등락률, 거래량 비교
- 수익률과 거래대금 기준의 주요 ETF 확인
- 국내 ETF 시장의 업종·테마별 흐름 탐색

분석 결과를 바탕으로 관심 ETF의 성과와 시장 동향을 간단히 파악하는 것을 목표로 합니다.

## 실시간 대시보드

네이버 금융 ETF 시세 API를 60초마다 조회해 다음 정보를 제공합니다.

- 전체 ETF 시장 요약과 상승·하락 종목 비율
- 운용사별 종목 수, 시가총액, 평균 등락률
- 시장 분류별 규모와 성과 비교
- 상품 전략별 조회와 종목 검색·정렬
- 개별 ETF의 가격, NAV 괴리율, 거래대금 상세 정보

브라우저의 CORS 제한과 EUC-KR 응답 처리를 위해 내장 프록시 서버를 사용합니다.

```bash
npm start
```

실행 후 `http://127.0.0.1:4173`에서 확인할 수 있습니다. 별도의 패키지 설치는 필요하지 않습니다.
